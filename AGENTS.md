# Operating manual bridge

This workspace's single operating manual is [CLAUDE.md](CLAUDE.md). Read it in full before doing anything. It contains the routing table, the evidence rules, and the decision boundaries, and all of them apply to every assistant.

The commands live in `.claude/skills/` (`start`, `audit`, `feedback`). In a runtime that does not load Claude skills, read the matching `SKILL.md` and follow it as a procedure.
